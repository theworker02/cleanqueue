# cleanqueue

Clean filesystem queue paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/cleanqueue/

## Install / run

```bash
git clone https://github.com/theworker02/cleanqueue.git
cd cleanqueue
node src/cli.js
node --test
```
